# 竞品分析与个人自用小工具建议

> 结论先行：**"拆爆款视频"这个需求已有四类玩家，但没有一个是"面向个人、输入链接即出运营视角拆解报告、数据沉淀本地"的轻量工具——这正是个人自建工具的定位空间。** 建议走"零代码验证 → 轻量自建 MVP"的路线，先 B 站/YouTube 两个平台，总成本可控制在每年几百元内。

---

## 一、竞品全景（2025-2026）

按定位分四类，各有明显盲区：

| 类别 | 代表产品 | 强项 | 盲区（=你的机会） |
|---|---|---|---|
| ① 平台官方免费工具 | [抖音热点宝](https://www.deepnavi.cn/ai-new-media/dou-yin-re-dian-bao)、巨量算数、巨量创意、TikTok Creative Center | 免费、数据最权威、选样和热点强 | 只给"哪些视频火"，不给"为什么火"的逐秒拆解 |
| ② 数据平台 SaaS（付费） | 蝉妈妈（已出[《蝉妈妈AI》App](https://apps.apple.com/mo/app/%E8%9D%89%E5%A6%88%E5%A6%88ai/id6747111630)）、飞瓜数据、新抖、考古加、抖查查、千瓜/灰豚 | 榜单、达人、电商数据全 | 贵（年费数千元级）、面向团队、AI 深拆（钩子/结构/节奏）刚起步且浅 |
| ③ AI 拆解工具（链接→拆解） | [VideoLens](https://chromewebstore.google.com/detail/videolens-%E2%80%94-ai-video-brea/ccmnlkloekhaenffbhboofkbbgblffpf)（Chrome 插件）、[VideoFlow](https://global.v2ex.co/t/1230842)（网站+API+MCP）、[prompt-lens](https://github.com/raojiacui/prompt-lens)（开源）、[VideoNote-MCP](https://github.com/HuangYincan/VideoNote-MCP)（开源）、[VidPMT](https://www.producthunt.com/p/vidpmt/vidpmt) | 一键拆解、反推提示词 | 面向 **AI 视频创作者**（反推提示词复刻画面），不是面向**内容运营**（钩子/结构/数据/评论），且拆解结果不留存、不成库 |
| ④ 通用 AI 笔记/转写 | [NotebookLM](https://www.pocket-lint.com/notebooklm-youtube-video-watching/)（YouTube 链接→摘要）、通义听悟、飞书妙记、剪映、ChatGPT/Gemini/Claude/豆包多模态 | 免费/便宜、转写总结强 | 通用"总结"视角，不懂运营拆解维度，输出格式与你的方法论不对齐 |

**海外同类**：Snagly（TikTok Hook Analyzer 插件）、[TikTok Viral AI Hunter](https://apify.com/adray_soft/tiktok-viral-ai-hunter)（Apify API）、[ViralScriptAI](https://github.com/David7Mejia/ViralScriptAI)（开源）、[ViralGuru](https://apps.apple.com/cn/app/%E7%97%85%E6%AF%92%E5%BC%8F%E4%BC%A0%E6%92%AD%E6%B4%9E%E5%AF%9F-viralguru/id6749723213)（App）、Revid/Inflowave 的网页版 viral video analyzer——同样偏"提示词反推"或"广告素材分析"，无一覆盖"中文平台 + 运营视角 + 本地沉淀"的组合。

**竞品空白点**：没有一款工具解决"把爆款拆成**我的钩子库/脚本库**"这件事。数据平台给数据、AI 工具给拆解，但拆解结果都属于平台方，用户攒不下自己的公式资产。

---

## 二、个人工具定位建议

- **做**：输入视频链接 → 按你的七维模板输出拆解报告 → 自动沉淀进本地库（钩子库/选题库/脚本库）→ 支持检索和公式复用；
- **不做**：榜单采集（用抖音热点宝/蝉妈妈免费版选样即可，互补不重复）、团队协作、全网素材库；
- **核心资产是"拆解 prompt 模板"**：你上一份调研报告里的七维模板 + 钩子类型清单就是别人抄不走的差异化，工具只是执行它。

---

## 三、三个落地路径（从轻到重）

### 路径 A：零代码（今天就能开始，验证方法论）
1. 用剪映/通义听悟导出逐字稿（带时间戳）；
2. 把《爆款视频拆解模板》的"问题清单"做成 Claude Projects / ChatGPT 自定义 GPT / 豆包智能体的固定指令，把逐字稿+关键帧喂进去拿初拆；
3. 人工校准后录入飞书多维表格（用配套的拆解表.csv 字段）。
- 成本：0；目的：先确认"这套拆解流程对自己真的有价值"，再决定是否写代码。

### 路径 B：轻量自建 MVP（推荐，1-2 天可出第一版）
```
粘贴链接 → yt-dlp 下载 → ASR 转写 → LLM 按七维模板拆解(JSON) → 渲染 Markdown + 入库
```
- 形态：**本地 CLI 脚本起步**（一条命令出报告），跑通了再加一个简单本地 Web 页（FastAPI + 一个 html）；
- 技术选型：
  | 环节 | 选型 | 说明 |
  |---|---|---|
  | 下载 | yt-dlp（B站/YouTube 最顺）；抖音/小红书用 videdown 类开源方案 | [videdown](https://github.com/cshuangyy/videdown) 支持抖音/小红书/B站/YT 无水印；接口易变需容错 |
  | 转写 | faster-whisper 本地（免费）或通义听悟 API | 中文口播本地 Whisper 够用；量少时商用 ASR 更准 |
  | 拆解 | DeepSeek / 豆包 / GLM API（都便宜） | 用 JSON Schema 强约束输出七维字段，prompt 版本化管理 |
  | 存储 | 本地 Markdown + CSV，或 SQLite；后续接飞书多维表格 API | 先本地，别一上来搞数据库和登录 |
- 成本估算：转写本地跑免费；LLM 每次拆解约几分钱~几毛钱（按视频长度和模型）；一年用几百次也就几十元级；
- 平台优先级：**B站 → YouTube → 抖音 → 快手/小红书/视频号**（[ClipVault](https://github.com/kylesean/ClipVault)、[uvd](https://github.com/userwanyong/uvd) 等开源项目可参考封装，[yt-dlp 二次开发教程](https://cloud.tencent.cn/developer/article/2509252)）。

### 路径 C：基于开源改造（省 60% 工作量）
直接改 [VideoNote-MCP](https://github.com/HuangYincan/VideoNote-MCP)（下载/字幕/转写/弹幕/评论/LLM/导出全都有，9 种笔记风格）或 [prompt-lens](https://github.com/raojiacui/prompt-lens)：**只替换它的"笔记风格模板"为你自己的七维拆解模板**，即可获得成品级管线。适合不想碰下载/转写细节的情况。

## 四、MVP 功能清单

| 优先级 | 功能 |
|---|---|
| P0 | 粘贴链接 → 下载 → 转写 → 七维拆解报告（Markdown）→ 追加本地库 |
| P0 | 拆解 prompt 模板可编辑（不写死在代码里） |
| P1 | 批量拆解（一次 3-5 条，对应 SOP 的选样批量） |
| P1 | 钩子库检索（按钩子类型/赛道/公式关键词） |
| P2 | 简单本地 Web 页 + 弹幕/评论采集（对齐 VideoNote-MCP 的维度） |
| P2 | 数据快照自动抓取（点赞/完播——可手动填先） |

## 五、避坑指南

1. **平台接口会变**：抖音/小红书的无水印解析依赖第三方方案，随时可能失效——下载环节做成"可替换插件"，失败时降级为"手动导入本地视频文件"；
2. **别一上来做 UI**：先 CLI + Markdown 自用一周，确认拆解质量，再决定要不要页面；
3. **合规**：下载仅限学习研究自用；拆解结果不发布、不商用；
4. **转写选型**：中文口播多、有方言/口音时，Whisper 效果打折，可混用通义听悟（免费额度）；
5. **prompt 是核心竞争力**：每次拆解完对照人工精拆结果，迭代模板；模板用 JSON Schema 输出，方便后续做库。

---

## 六、建议的第一步

1. 本周先用**路径 A** 手工拆 3 条（B站 2 条 + 抖音 1 条），验证模板；
2. 同时我用**路径 B** 搭 CLI 骨架：`拆解工具 <链接>` 一条命令出报告；
3. 跑通后按你的使用反馈迭代。
